# Matriz de brechas frente a la plataforma de referencia

Documento de trabajo: compara la lista de capacidades que se pidió igualar con lo que el
código de este repositorio realmente hace. No es material de venta. La columna "Estado"
describe el código, no una ambición.

## Cómo juzgar la lista

La comparación útil no es "¿está la palabra?" sino tres preguntas encadenadas:

1. **¿Existe la superficie?** Si la función se puede tocar desde la API o la UI.
2. **¿Qué la respalda?** Un mecanismo real (contenedor, Kubernetes, Postgres, git) o una
   promesa de marketing. Cualquier cosa que termine en "sale un humano por detrás" es una
   deudas que crece con cada cliente.
3. **¿Qué falla primero cuando hay adversarios?** Cobrar, dejar de cobrar, un empleado
   desleal, un cliente que quiere irse. Harness está escrito alrededor de esa tercera
   pregunta; la lista de referencia, no.

| IDE listo para usar con 50+ lenguajes            | **Parcial y por diseño.** Hay 5 plantillas (`react`, `node`, `python`, `fastapi`, `html`) y el entorno es una imagen fija por plantilla (`node:22-bookworm-slim`, `python:3.12-slim`, `nginx:1.27-alpine`) bajo gVisor. Cualquier lenguaje extra existe escribiendo una receta, no instalando un paquete.                                                                     | Bajo para plantillas, medio para la superficie: 1 imagen nueva ≈ media jornada (receta, icono, `runtimeClassName`, prueba de arranque). 50 lenguajes es un problema de soporte, no de código: 50 imágenes que alguien parchea de seguridad para siempre.           |

## Qué se sumó en este PR y qué no

Este PR toca **portabilidad y ciclo de vida**: bundle Docker-export, importación de archivos,
versiones de código con restauración verificada, y la plantilla FastAPI.

Explícitamente **no** se agregaron, porque no se puede simular sin mentir: facturación y free
tier, colaboración CRDT en vivo, marketplace de extensiones propietario, prebuilds con caché
de imágenes, máquinas dedicadas, bases de datos gestionadas por proyecto, ni un `Dockerfile`
arbitrario del usuario como definición del entorno. Si algo de esto aparece en la tabla de
ventas antes que en el código, es una deuda, no una capacidad.
